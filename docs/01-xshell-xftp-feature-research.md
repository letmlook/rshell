# Xshell + Xftp 完整功能调研 & Rust+GPUI 实现方案

> 调研日期：2026-07-29  
> 目标：梳理 Xshell + Xftp 全部功能，为使用 Rust + GPUI 开发原生替代软件提供依据。

---

## 一、Xshell 功能全景

### 1. 协议支持

| 协议 | 说明 |
|------|------|
| SSH1 / SSH2 | 安全 Shell 连接，支持 PKCS#11 硬件令牌 |
| Telnet | 远程登录协议 |
| Rlogin | 远程登录（类 Unix 系统） |
| SFTP | SSH 文件传输协议（内嵌） |
| Serial | 串口连接（IoT / 嵌入式场景） |
| RDP | 远程桌面协议（Xshell 8 新增） |

### 2. 会话管理

- **会话管理器**：树形文件夹结构组织会话，支持批量编辑属性
- **可继承会话属性**：文件夹级属性模板，新建会话自动继承
- **认证配置文件**：保存认证变量集，一次修改多处生效
- **快速连接**：地址栏直接输入 URL / 命令连接，无需保存会话
- **自动登录**：等待-响应脚本（Expect 模式）
- **跳转主机（Jump Host）**：通过中间 SSH 代理到达目标服务器
- **最近会话列表**：快速访问最近连接的服务器
- **多会话同时连接**：批量建立多个主机连接
- **链接栏快捷方式**：会话支持快捷方式引用

### 3. 终端仿真

- **终端类型**：VT100、VT220、VT320、Xterm、Linux、SCO ANSI、ANSI
- **Unicode / UTF-8 支持**：单终端显示多语言
- **2 字节字符支持**：CJK 完整支持
- **滚动缓冲区**：32767 行
- **正则表达式搜索**：终端文本搜索
- **列选择 / 三次点击选行**
- **分隔符双击选择**
- **粗体字体 & ANSI 转义序列颜色**
- **终端打印（网络打印）**
- **可配置行间距和边距**
- **光标颜色和闪烁速度自定义**

### 4. 界面与布局

- **标签式环境**：多会话标签管理
- **标签管理器**：树状结构查看所有标签 / 标签组
- **可拆分面板**：水平 / 垂直分割窗口
- **可停靠 UI**：自由拖放任意面板
- **布局管理**：自定义布局模式，即时切换
- **全屏模式**（Alt + Enter）
- **透明度选项**
- **可调节工具栏**
- **状态栏**：安全锁、选中会话、网络上下行流量
- **字体栏**：快速选择字体
- **配色方案**：编辑 / 导入 / 导出，多深色 / 浅色主题
- **突出显示集**：通过关键字 / 正则高亮终端输出

### 5. 效率工具

- **快速命令管理器**：创建常用命令按钮，一键执行
- **撰写窗格（Compose Pane）**：多行文本草拟后发送到单 / 多 / 全部会话
- **同步输入**：输入同时发送到多个选中的终端
- **触发器（Triggers）**：终端出现指定字符串时自动执行操作
- **脚本录制**：根据终端 I/O 自动生成脚本
- **VB / JS / Python 脚本支持**：自动化重复任务
- **用户定义键映射**：自定义键盘快捷键
- **本地 Shell**：在 Xshell 内直接使用 Windows CMD
- **SCP 命令支持**：本地 Shell 中直接 SCP 传输

### 6. 安全

- **认证方式**：密码、RSA / DSA / ECDSA / ED25519 公钥、键盘交互、GSSAPI (Kerberos)、PKCS#11
- **加密算法**：AES128 / 192 / 256、3DES、Blowfish、CAST128、Arcfour、Rijndael
- **MAC 算法**：SHA1、MD5、SHA1-96、MD5-96、RIPEMD160
- **zlib 压缩**
- **主密码**：加密存储会话密码
- **自动锁定终端屏幕**
- **主机密钥管理**
- **用户密钥管理**：生成向导 + 导入 / 导出
- **SSH 认证代理转发**（Xagent）

### 7. 隧道与端口转发

- **TCP/IP 端口转发**：本地 / 远程端口转发
- **X11 转发**：与 Xmanager 互操作
- **动态端口转发**：SOCKS 代理
- **即时隧道**：运行中会话即时创建 / 管理 SSH 隧道
- **隧道栏**：监控活动代理通道，添加新规则

### 8. 文件管理

- **远程文件管理器**：可视化远程目录文件列表
- **Zmodem 拖放上传 / 下载**
- **SFTP 文件发送 / 接收**
- **ASCII 文件上传模式**
- **延迟发送**
- **自动会话日志**（含终端代码）

### 9. 互操作性

- **Xmanager**：X11 转发互操作
- **Xagent**：代理认证转发
- **Xftp**：一键从 Xshell 打开 Xftp 文件传输
- **第三方编辑器**：用外部编辑器打开终端内容
- **IPv6 完全支持**

## 二、Xftp 功能全景

### 1. 协议支持

| 协议 | 说明 |
|------|------|
| SFTP | SSH 文件传输协议 |
| FTP | 文件传输协议 |
| FTPS | FTP over SSL / TLS |
| SCP | 安全复制协议 |

### 2. 文件传输

- **拖放传输**：本地与远程之间拖放文件
- **传输队列管理**：管理传输任务队列
- **暂停 / 恢复**：断点续传
- **同时传输**：多线程并行传输，最大化带宽利用
- **FXP 支持**：服务器到服务器直传
- **传输调度**：按用户定义时间表自动传输
- **ASCII / Binary 模式自动切换**

### 3. 同步功能

- **文件夹同步**：比较、约定和同步本地 / 远程文件夹
- **同步浏览**：两台服务器间文件夹导航同步

### 4. 文件管理

- **双窗格界面**：本地 + 远程并排显示
- **快速文件搜索**：搜索 / 过滤当前目录文件和子目录
- **文件过滤**：按规则过滤杂乱内容
- **文件夹书签**：收藏常用路径
- **Windows 上下文菜单**：右键直接传输文件
- **直接编辑**：远程文件直接编辑保存
- **图片缩略图预览**
- **远程文件权限设置**

### 5. 会话管理

- **选项卡式界面**：多会话并行
- **可继承会话属性**：文件夹级模板
- **跳转主机代理**：通过中间服务器中转
- **保持活动选项**：Keep-alive 心跳
- **多样化代理服务器**：HTTP / SOCKS / FTP 代理

### 6. 安全

- **OpenSSH CA 认证**
- **PKCS#11** 硬件令牌支持
- **多种加密算法**：AES128 / 192 / 256、3DES、Blowfish 等
- **Kerberos 支持**
- **主密码加密**
- **RSA / DSA / ECDSA / ED25519 公钥**
- **密码及键盘交互认证**
- **SHA1 / MD5 / RIPEMD160 MAC 算法**
- **zlib 压缩**

### 7. 互操作性

- **Xshell 联动**：从 Xftp 一键打开 Xshell 终端会话
- **Xshell 命令行访问**
- **第三方编辑器集成**

## 三、Rust + GPUI 技术选型方案

### 核心框架

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **UI 框架** | GPUI 0.2 + gpui-component 0.5 | Zed 编辑器同款 GPU 渲染框架，60+ 原生组件 |
| **SSH 协议** | `russh`（纯 Rust） | 异步、Tokio 友好、支持客户端 / 服务端、自定义加密后端 |
| **SFTP** | `russh-sftp` | 基于 russh 的 SFTP 子系统实现 |
| **FTP / FTPS** | `suppaftp` | Rust FTP 库，支持 FTPS (TLS) |
| **Telnet** | 自实现（基于 Tokio TCP + Telnet 协议解析） | Telnet 协议较简单 |
| **Serial** | `serialport` crate | 跨平台串口通信 |
| **终端仿真** | `alacritty_terminal` 或 `vt100` | Alacritty 的终端仿真引擎，支持 VT100/220/320/Xterm 等 |
| **SSH 密钥** | `russh-keys` / `ssh-key` | 密钥生成 / 导入导出 / 管理 |
| **加密** | `ring` / `rustls` | 现代加密库 |
| **脚本引擎** | `rhai` 或 `rlua` | 嵌入式脚本语言支持 |
| **Zmodem** | `zmodem` crate 或自实现 | 文件传输协议 |
| **配置存储** | `serde` + `toml` / `json` | 会话配置持久化 |
| **密钥环** | `keyring` crate | 系统级安全密码存储 |

### 关键实现难点 & 建议

| 难点 | 建议 |
|------|------|
| **终端渲染** | GPUI 中嵌入终端渲染是最大挑战。建议参考 Alacritty 的 `alacritty_terminal` 做 VT 解析，用 GPUI 的 GPU 渲染做字符绘制。或考虑用 WebView 组件嵌入 `xterm.js` 作为过渡方案 |
| **PTY 伪终端** | Windows 下用 `ConPTY` API，Linux / macOS 用 `posix_openpt`。Rust crate `portable-pty` 可跨平台封装 |
| **SFTP 双窗格文件管理器** | GPUI Component 的虚拟化 `Table` 组件非常适合大目录渲染 |
| **Dock 布局** | GPUI Component 内置 `Dock` + `Tiles` 布局，直接复用 |
| **脚本引擎** | 用 `rhai` 实现类 VB 脚本能力，或用 `rlua` 嵌入 Lua |
| **Zmodem** | 较冷门协议，可能需要参考 `lrzsz` 自实现 |
| **RDP 支持** | 可考虑集成 `ironrdp`（纯 Rust RDP 实现） |
| **跨平台** | GPUI 天然支持 Windows / macOS / Linux，但 Serial / ConPTY 需平台适配 |

### 开发路线建议（分阶段）

**Phase 1 - MVP（核心终端）**
- SSH 连接（russh）+ 终端仿真（alacritty_terminal）+ GPUI 终端渲染
- 会话管理（创建 / 编辑 / 删除 / 连接）
- 标签式多会话
- 基本终端功能（滚动、搜索、复制粘贴）

**Phase 2 - 文件传输**
- SFTP 文件管理器（双窗格）
- 拖放传输、传输队列、断点续传
- 文件夹同步

**Phase 3 - 效率工具**
- 快速命令、撰写窗格、同步输入
- 触发器、脚本引擎
- 端口转发 / 隧道管理

**Phase 4 - 完善**
- Telnet / Rlogin / Serial 协议
- 配色方案管理、主题系统
- Zmodem、RDP
- 主密码、密钥管理
- 会话导入 / 导出（兼容 Xshell 格式）
