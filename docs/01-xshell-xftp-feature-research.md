# 产品范围与研究结论

更新：2026-09-26。本文件解释 RShell 的范围选择，不再维护未经验证的竞品版本、价格或功能对照。

## 当前定位

RShell 是 macOS 上的远程终端与 SFTP 工作区。保留 SSH、Telnet、Serial、会话管理、终端、SFTP、Local/Dynamic 隧道、SSH 密钥、主机密钥确认、快速命令、触发器、Rhai、主题及 WASM 模块加载。

本轮保留现有工作区布局与协议库，目标是消除假数据、空操作、错误状态、事件泄漏和不可靠的连接生命周期，不追求新增功能数量。

## 范围收缩

RDP 已移出产品并删除实现与公共类型。Remote Forward 不提供新建入口，历史规则保留并报告不支持。FTP/FTPS、Windows ConPTY、截图和录屏不属于本轮交付。

快速命令与触发器界面不代表完整脚本 IDE。WASM 模块能编译、加载、卸载，不代表动态界面、插件市场或完整宿主权限接口已经实现。主密码加密服务不等于所有会话凭据已加密。

## 判定原则

- 可见操作有真实结果或明确的禁用原因。
- 不用本地示例数据掩盖远端错误。
- 单元测试、进程启动、GUI 手测和真实服务器验证分别记录。
- 当前状态见 [功能与限制](08-incomplete-features.md) 和 [验证记录](09-macos-validation.md)。

早期调研和旧架构设想可从 Git 历史查看，不作为当前实现承诺。
