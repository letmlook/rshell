# 项目实施状态

更新：2026-09-26。目标平台是 macOS；不扩展功能范围，不推进 Windows。

## 本轮内容

1. 删除 RDP 公共协议、运行时模块和直接依赖，旧协议输入拒绝解析。
2. 隧道限制为 Local/Dynamic，保留并跳过旧 Remote 规则。
3. SFTP 目录、上传、下载、新建目录和普通文件删除接入真实服务，增加路径校验与确认。
4. 终端 I/O、尺寸、连接状态、触发器与脚本宿主连通；快速命令和触发器落盘恢复。
5. 主题与配色同步，事件监听可释放；WASM 模块加载执行实际编译校验。
6. 修复 macOS 初始化嵌套运行时问题，补充连接取消、退出和通道隔离回归。
7. 更新用户文档，区分已实现、已自动验证和待真实环境验收。

原始实施步骤保留在 [带日期的计划](superpowers/plans/2026-09-25-macos-hardening.md)，它是执行记录，不是当前产品手册。
